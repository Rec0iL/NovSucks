# SSG24

Novritsch SSG24 — bolt-action airsoft sniper rifle. The SSG24 is essentially a pre-upgraded, modified version of the **Modify MOD24** (also known as the MOD24X / USR150 / SF) platform, built on the classic **APS-2** internal architecture (this is distinct from the VSR-10 system used in the SSG10).

## Known quirks / notes

- **Modify MOD24 Compatibility**: Internals are almost 100% interchangeable with the Modify MOD24 series. If you need replacement cylinders, pistons, spring guides, trigger sears, or hop-up buckings, you can search directly for Modify MOD24 upgrade parts.
- **Top-Tier Aftermarket Support (Tridos Design)**: The aftermarket community heavily relies on **Tridos Design**, who manufactures specialized precision upgrades specifically for the SSG24/MOD24. These include the **TDC 2.0 Hop-Up conversion** (for external thumbscrew vertical adjustment), **M4 Magazine Adapters**, **SORA/Snipetor R-Hop arms**, and protective trigger/safety dust covers.
- **Springs & Tuning**: Uses standard APS-2 / MOD24 outer diameter springs. Brands like **Rapax** and **Modify** offer specialized sniper springs calibrated for smooth pull and precise Joule ratings (e.g., Rapax 2J, 3J springs) without piston binding.
- **Magazines**: Uses Modify MOD24 magazines. Some CYMA / Snow Wolf M24 magazines can function as affordable alternatives with minor filing/fitting, though they lack the translucent BB-counting window found on standard SSG24/MOD24 magazines.
- **External Tolerances**: While internal mechanical parts match the MOD24/MOD24X, external furniture (such as outer barrels, stock bedding, and receiver top rails) may have slight proprietary tolerances or threading depending on the generation and production batch. Always verify external accessory compatibility before purchasing.
